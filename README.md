# Outfit Castle

**A project made for a gamejam with the objective to create a player customization mechanic.**

Get to the wardrobe and select a combination of clothes for your character!

---

## Assets
**Free assets from itch.io ->** Wardrobe, Tileset and base character

**Made by me ->** Pixel art clothes and shoes

## 🛠️ Technologies Used

- **Godot 4.5**  
- GDScript  
- Free Pixel-art assets from itch.io
- Aseprite
